# Sharing & Recruiting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users tap a "Compartir" button to generate a branded image card and share it (with optional group invite code) to WhatsApp, Instagram Stories, or any app via the native OS share sheet.

**Architecture:** A `ShareCard` component renders the visual card off-screen (outside the viewport). A `useShareCard` hook captures it with `html2canvas`, then calls the Web Share API with the PNG file, falling back to text-only sharing or clipboard copy. A `ShareButton` component wires the two together and is dropped into Dashboard, LeaderboardPage, and GroupLeaderboard.

**Tech Stack:** React 18, html2canvas, Web Share API, Clipboard API, Vitest + @testing-library/react, Tailwind CSS, Bebas Neue + Noto Sans (already loaded in the app).

- [ ] **Step 1: Create the hook**

Create `src/hooks/useShareCard.js`:

```js
// src/hooks/useShareCard.js
import { useState } from 'react'
import html2canvas from 'html2canvas'

const APP_URL = 'https://quiniela-2026.netlify.app'

export const useShareCard = (cardRef, { displayName, rank, points, groupName, inviteCode }) => {
  const [sharing, setSharing] = useState(false)
  const [copied, setCopied] = useState(false)

  const getShareText = () => {
    const hasScore = points != null && points > 0
    if (!hasScore && groupName) {
      return `¿Te animas a la quiniela? Únete a ${groupName} con el código ${inviteCode}. Juega Quiniela 2026 — ${APP_URL}`
    }
    return `¿Crees que me puedes ganar? Llevo ${points} puntos en el lugar #${rank}. Juega Quiniela 2026 — ${APP_URL}`
  }

  const share = async () => {
    if (!cardRef.current || sharing) return
    setSharing(true)
    try {
      const canvas = await html2canvas(cardRef.current, { useCORS: true, scale: 2 })
      const blob = await new Promise(resolve => canvas.toBlob(resolve, 'image/png'))
      const file = new File([blob], 'quiniela-26.png', { type: 'image/png' })
      const text = getShareText()

      if (navigator.share) {
        if (navigator.canShare?.({ files: [file] })) {
          await navigator.share({ files: [file], text, url: APP_URL })
        } else {
          await navigator.share({ text, url: APP_URL })
        }
      } else {
        await navigator.clipboard.writeText(text)
        setCopied(true)
        setTimeout(() => setCopied(false), 2000)
      }
    } catch (err) {
      // User cancelled share dialog — not an error
      if (err?.name !== 'AbortError') console.error(err)
    } finally {
      setSharing(false)
    }
  }

  return { share, sharing, copied }
}
```

        </div>

  )
